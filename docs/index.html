ツール概要

Xのタイムラインから24時間以内のAI関連ニュースを自動収集し、Geminiで分析してSlackに投稿するツール。
毎朝7:30に自動実行され、その日の主要AIニュースをSlackに届ける。

ツール概要

AIニュース版を応用して作成。世界7カ国・地域の水素関連ニュースをGoogle News RSSから自動収集し、Geminiで日本語分析してSlackに投稿するツール。
X API不要で完全無料で動く。

AIニュース版との違い

ソース AIニュース版
X（Twitter）のホームタイムライン。フォロー中のアカウントの投稿のみ。X API の費用がかかる。
ソース 水素版
Google News RSS。キーワード検索で世界中のニュースを取得。X API 不要・完全無料。
URL本文取得 AIニュース版
Jina Reader で各URLの本文を別途取得してから要約する。
URL本文取得 水素版
RSSにすでに記事の説明文が含まれるためスキップ。処理が速くコストも低い。
