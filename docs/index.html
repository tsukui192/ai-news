水素市場ニュース
自動配信ツール

世界7カ国・地域の水素関連ニュースを毎朝自動で収集し、AIが日本語でトレンド分析してSlackに届けるツール。 コードで自動化することで、毎日手作業でニュースを調べる手間をゼロにした。

各ステップの詳細

それぞれのステップで何が起きているかを解説する。

起
GitHub Actions が毎朝自動で起動する
サービス: GitHub Actions（無料）
GitHub Actions は「スケジュールを決めてプログラムを自動実行できるクラウドサービス」。
毎朝7:30（日本時間）になると自動でツールが動き出す。自分のPCの電源が入っていなくてもクラウド上で動くため、完全に手離れした自動化が実現できる。
設定ファイル（.github/workflows/hydrogen-news.yml）に「毎朝22:30 UTC（= 07:30 JST）に実行」と1行書くだけで動く。
①
世界7カ国・地域のニュースをまとめて収集する
サービス: Google News RSS（無料）
Google News は「水素」「hydrogen」などのキーワードで世界中のニュースを検索できる。その検索結果をRSS（ニュースの一覧データ）として自動で取得する。

米国・欧州・中国・韓国・オーストラリア・台湾・日本の7地域を同時に監視し、24時間以内に公開されたニュースだけを収集する。 同じ記事が重複していた場合は自動で除去する。
もともとのAIニュース版はX（Twitter）のAPIを使っていたが、水素版ではGoogle News RSSに切り替えることでX APIの費用（月約$75）をゼロにできた。
②
AIが収集したニュースをトレンド分析して日本語でまとめる
サービス: Gemini 2.5 Pro（無料枠内）
収集したニュース記事をすべてGoogleのAI「Gemini 2.5 Pro」に渡す。AIは内容を読み込み、「主要ニュース」「注目アップデート」「技術トレンド」の3カテゴリに分類して日本語でまとめる。

英語・中国語・韓国語のニュースも自動的に日本語で要約されるため、多言語対応が不要になる。
AIへの指示（プロンプト）に「水素市場の観点で分析し、国・地域ごとの動向を意識すること」と書くことで、水素に特化した分析ができる。
③
分析結果を見やすいカード形式でSlackに投稿する
サービス: Slack（無料プラン）
AIの分析結果をSlackの「Block Kit」という形式で整形して投稿する。Block Kitはテキストをカード状に並べる機能で、タイトル・詳細・ソースURLがセットになった見やすいレポートが自動生成される。

毎朝Slackを開くだけで、その日の世界の水素市場の動向を日本語で把握できる。
Slackに投稿するボット（AIニュースBot）を作成し、特定のチャンネルに招待するだけで設定完了。

なぜこの7カ国・地域を選んだのか

水素市場で注目度が高い国・地域を中心に選定した。

🇺🇸
米国
hydrogen market / green hydrogen
世界最大の水素投資国。IRA（インフレ抑制法）による巨額補助金が水素産業を後押しする。
🇪🇺
欧州
hydrogen energy Europe
EUが「水素戦略」を国家レベルで推進。ドイツ・オランダ・スペインが主要プレーヤー。
🇨🇳
中国
hydrogen China / 氢能
世界最大の水素生産国。国家戦略として積極的に投資しており、燃料電池バスの普及が進む。
🇰🇷
韓国
hydrogen Korea / fuel cell
現代自動車・SKグループなど大企業が燃料電池・水素自動車に注力している。
🇦🇺
オーストラリア
green hydrogen Australia
太陽光・風力が豊富で安価なグリーン水素の生産・輸出国として日本への供給拠点になりうる。
🇹🇼
台湾
hydrogen Taiwan
脱炭素政策の一環として水素の活用研究・実証実験が進んでいる。
🇯🇵
日本
水素 市場 / グリーン水素
「水素基本戦略」を国家政策として推進。トヨタ・川崎重工・岩谷産業などが牽引する。

Slackに届くレポートの構成

AIが分析した内容を3つのカテゴリに整理して毎朝届ける。

🔥 主要なニュース・話題
その日の水素市場で最も重要なニュース。
  • 大型プロジェクトの発表
  • 各国政府の政策決定
  • 企業間の提携・合意
  • 大規模投資のニュース
⚡️ 注目のアップデート
水素市場の最新動向のアップデート情報。
  • 補助金・規制の変更
  • 実証実験の進捗報告
  • 水素価格・コストの変化
  • 各国の目標達成状況
💡 技術トレンド
水素に関する技術革新の動向分析。
  • 水電解技術の進歩
  • 輸送・貯蔵の革新
  • 燃料電池の最新動向
  • コスト削減の技術
